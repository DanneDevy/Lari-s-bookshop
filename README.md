# Lari-s-bookshop
A Lari's Bookshop nasceu inspirada na minha namorada em Larissa, por isso o nome, ela é apaixonada por livros. O projeto busca criar uma livraria virtual acolhedora, elegante e acessível, unindo conforto, sofisticação e emoção. Além de representar a paixão pelos livros, também marca meu aprendizado e evolução como desenvolvedor web.
